# Hall Booking Portal

A web-based hall booking system designed to simplify and streamline hall reservations within an institution.

The platform allows users to check hall availability, submit booking requests, and manage their reservations. Administrators can manage halls and users, review booking requests, and approve or reject reservations through an administrative dashboard.

## Features

- **User Authentication** – Secure user login and access management
- **Hall Availability** – Check hall availability before making a reservation
- **Online Hall Booking** – Submit booking requests through the application
- **Booking Management** – View and manage existing reservations
- **Booking Approval** – Administrators can approve or reject booking requests
- **Booking History** – Track previous and current bookings
- **User Management** – Administrators can manage registered users
- **Hall Management** – Administrators can manage available halls
- **Admin Dashboard** – Centralized dashboard for managing halls, users, and bookings

## Application Flow

1. Users authenticate through the application.
2. Users check the availability of halls.
3. Users select a hall and submit a booking request.
4. Booking requests are stored and managed through the system.
5. Administrators review pending requests.
6. Administrators can approve or reject requests.
7. Users can view their booking status and booking history.
