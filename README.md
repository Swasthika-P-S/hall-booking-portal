# Hall Booking Portal
Hall Booking Portal is a web-based application that streamlines the process of booking halls within an institution.
Users can check hall availability, submit booking requests, and manage their reservations, while administrators
can approve or reject requests and manage halls and users.

## Features

- User authentication
- Hall availability checking
- Online hall booking
- Booking approval and rejection by admin
- Booking history
- User and hall management
- Dashboard for administrators

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose

## Installation

```bash
git clone https://github.com/Swasthika-P-S/hall-booking-portal.git
```

```bash
cd hall-booking-portal
npm install
npm start
```
